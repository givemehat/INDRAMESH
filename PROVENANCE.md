# Provenance and originality statement

SIH26164 · IndraMesh · Enterprise Cryptographic Discovery & Analysis Tool

This document exists to answer one question unambiguously: **what in this repository is ours?**

## The short answer

**All executable code in `engine/`, `app.py`, `cli.py`, `cli_advanced.py`, `benchmark/` and
`tests/` was written for this project.** No third-party source code was copied, vendored, or
adapted from any other project.

## What was consulted, and what was taken

Public prior art was studied, as any engineer would. The distinction we maintain is between
**reading an idea** and **taking code**:

| Consulted | How | What was taken |
|---|---|---|
| CycloneDX 1.7 specification and JSON Schema | the published standard | The **vocabulary** (`primitive`, `nistQuantumSecurityLevel`, `assetType`). The schema is vendored from the standard's own published artefact, unmodified, and checksummed. |
| NIST FIPS 197/180-4/203/204/205, SP 800-52r2, IR 8547 | published standards | **Parameter sizes and normative text.** These are facts, not code. |
| Mosca's inequality; GRI/evolutionQ expert survey | published literature | The **formula** and the published Z-window. |
| Open Source ACDI & Static Analysis ecosystem | Public technical specifications & papers | Analyzed architectures, taxonomies, and gaps to independently design our assurance tiers and formal purpose resolver. |

The ideas that shaped our design — the assurance taxonomy and the purpose model — are
implemented independently: our own function signatures, our own resolution logic, our own error handling, our own tests.

## Third-party code that exists in the working tree, and why it is not ours

`benchmark/corpora/` contains **cloned upstream repositories used as benchmark input**:

| Corpus | Licence | Role |
|---|---|---|
| CryptoAPI-Bench | MIT | measurement input |
| paramiko | LGPL-2.1 | measurement input |
| golang.org/x/crypto | BSD-3-Clause | measurement input (Go standard library's official crypto library) |

The Go corpus is a **three-file slice** of `x/crypto`'s `ssh/` package: `cipher.go`, `mac.go` and
`mlkem.go`. The other 28 non-test files in that package are cloned but neither annotated nor
scanned. The pin covers the whole clone; the measured scope is those three files, and the scope
is declared in `benchmark/annotate.py` and in the label file's `scope_caveat`.

- These are **excluded from version control** by `.gitignore` and have **never appeared in any
  commit** — verifiable with `git log --all -- benchmark/corpora`, which returns nothing.
- They are re-fetched at a pinned commit SHA by `benchmark/run_benchmark.py`, so the measurement is
  reproducible without redistributing someone else's code.
- Nothing in `engine/` imports from them. They are read as *data*.

Shipping a competitor's source in your submission would be a licensing and originality problem.
This is deliberately structured so that does not happen.

## Third-party runtime dependencies

Declared, installed from PyPI, and not redistributed here: `torch`, `scikit-learn`, `pandas`,
`numpy`, `jsonschema`, `streamlit`, `pyvis`, `javalang`. The optional PyTorch model
(`engine/ml/`) was trained by this project on data generated by `engine/ml/generate_data.py`.

## How to verify every claim on this page

```powershell
# 1. No third-party code is tracked, and never was
git log --all --oneline -- benchmark/corpora      # empty
git ls-files benchmark/corpora                     # empty

# 2. Our code imports only the standard library and declared PyPI packages
Select-String -Path engine\*.py,app.py,cli.py,cli_advanced.py -Pattern '^\s*(from|import)\s+\S+'

# 3. The full test suite passes
python -m pytest tests -q

# 4. The defect-detection rate, not just the test count
python mutation_test.py
```

## On the architecture research
 
We studied publicly available specifications and research on the post-quantum problem statement.
We did not use external project code. Where industry ideas improved our design, we designed and
wrote our own formal implementations from first principles. That is the honest account, and it is the one we are willing to
stand behind.
